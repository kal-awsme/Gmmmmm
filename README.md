# schedule flow by VELLORA

Mobile-first personal schedule organizer.

## GitHub Pages
Upload `index.html`, `style.css`, and `app.js` to the repository root. In GitHub, open Settings → Pages and deploy from the `main` branch root.

## Features
- Separate Home, Tasks, Progress, and Settings views with fixed bottom navigation
- Create, edit, complete, and delete folders and tasks
- Priorities and Today / This week / This month / This year / All filters
- Calendar, focus timer, progress summary, active-day streak
- English and Indonesian interface
- Four color atmospheres, custom background photo, darkness and blur controls
- Optional deadline notifications (browser support and permission required)
- Local browser storage, demo reset, and clear local data

Data is stored in this browser using LocalStorage. This GitHub Pages build is not yet an installable offline PWA.
